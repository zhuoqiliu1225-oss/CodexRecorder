# 拾音录音笔 · 使用指南

[返回安装说明](../README.zh-CN.md) · [English](USAGE.md)

适用于 Windows 本地 Codex 与 CodexRecorder 预览版 0.2。当前不是免安装 EXE，也尚未支持 iOS。

## 1. 首次使用：先下载，再暖机

安装依赖不等于模型已经就绪。首次需要下载语音模型和约 500 MB 的翻译权重，再加载模型并预热。网速较慢、模型较大或使用 CPU 时可能需要数分钟或更久，没有统一的完成时间。

| 当前状态 | 应该怎么做 |
| --- | --- |
| 安装脚本正在下载 | 保持网络连接，等待脚本完成。下载失败时按错误说明重试。 |
| “正在加载并预热语音模型…” | 保持面板和服务打开。不要反复发“开始录音”或反复启动服务。此时尚未开始录音。 |
| 显示“GPU 低延迟转写”或“CPU 本地转写” | 模型已就绪，可以开始录音。 |
| 显示“正在录音”，计时增加 | 麦克风已经开始采集，可以讲话。 |
| 停止后“正在整理” | 录音已停止，正在补齐转写、翻译和总结，继续等待即可。 |

需要检查时，在项目目录运行 `node scripts/control.cjs status`，查看 `engine.status` 是否为 `ready`。重启电脑或后台服务后需要重新加载和暖机；已经缓存的模型通常无需重新下载。同一服务保持运行时，后续开始录音可以复用模型。

## 2. 在 Codex 中控制录音

安装个人技能后，可以在其他本机项目的新聊天中使用。新装技能没有出现时，开启新聊天。

| 目的 | 可以发送的内容 |
| --- | --- |
| 开始 | `$codex-recorder 开始录音` |
| 暂停 | “暂停录音” |
| 继续 | “继续录音” |
| 停止 | “停止录音” |

在本仓库内也可使用 `$recorder`。直接说“开始录音”通常可以触发技能；明确指定 `$codex-recorder` 更容易识别。聊天控制仍需要 Codex 处理指令的时间。

首次请手动允许麦克风访问。模型暖机期间、授权完成之前，不应把“已发送开始请求”当成“正在录音”。以面板状态和计时为准。面板上的开始、暂停、继续和停止按钮也可以直接操作。

暂停会停止采集新的语音，已有内容继续处理。停止后自动整理总结；GPT 总结需要网络、有效 Codex 登录及可用额度，可能比本地转写慢。无需填写 API Key。

## 3. 三种语言设置分别是什么

| 设置 | 作用 |
| --- | --- |
| 界面语言 | 中文 / English，即时切换并记住选择。只改变按钮、状态、标签和常见错误提示。 |
| 原文语言 | 你正在说的语言。可自动识别，也可手动指定；请在开始录音前选择。 |
| 实时翻译 / 翻译成 | 打开翻译，选择译文语言。可在录音中或录音结束后切换。 |

支持的识别与翻译选项包括中文、英文、日文、韩文、法文、德文和西班牙文。切换翻译目标后，已有内容会补译，后续文字也使用新语言；切回已翻译过的语言会复用缓存。

界面语言不会改写已保存的原文、译文或总结。目前自动总结默认用中文，尚未提供独立的总结语言选项。底层错误详情可能保留其原始语言。

## 4. 阅读、分段与复制

- 默认按约 1 分钟合并显示段落，可改为约 30 秒或 2 分钟。只是显示分组，转写仍按短片段持续更新，不必等到整段结束。
- 文字与总结区域高度固定，需要时在区域内部滚动。处理任务数变化不会把整个页面上下顶动；实时识别仍可能修订文字本身。
- 点击“复制原文”，复制当前全部原文，保留段落但不带时间戳和译文。
- 想复制部分内容或双语内容，可拖选文字后按 Ctrl+C；选区中的时间戳和处理提示会过滤。
- 选择文字期间，录音与保存继续，文字区域暂缓重绘，避免打断选区；取消选择后继续显示更新。

## 5. 停止、总结和导出

停止后先等转写与翻译补齐，再到“录音总结”查看结果。总结失败时，转写和录音仍然保留；修复登录或网络问题后可点击“重新生成总结”，也可请当前 Codex 聊天根据转写整理。

| 获取方式 | 内容 |
| --- | --- |
| “导出笔记” | Markdown 笔记，包含转写、所选译文和已有总结，保留时间信息。 |
| “下载录音” | 本次收到的 WAV 音频。 |
| 项目目录 `data/<会话ID>/` | `audio.wav`、`notes.md`、`session.json` 及音频分块。 |

新录音会替换面板上正在展示的记录，旧记录仍保存在各自的本机目录中。不要删除程序目录或把私人 `data` 目录上传到 GitHub。

音频与本地推理保留在本机。生成 GPT 总结或使用 GPT 翻译兜底时，相关转写文字会通过你的 Codex 登录发送给 OpenAI。

## 6. 常见问题与更新

| 问题 | 处理方式 |
| --- | --- |
| PowerShell 提示禁止运行脚本 | 可让 Codex处理，或对已检查的本仓库脚本使用一次性的进程执行策略：`powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1`；安装技能时把末尾脚本换成 `install_skill.ps1`。无需修改全局策略。 |
| Python / Node / Git 命令不存在 | 完成安装后重新打开终端，让 PATH 生效；有多个 Python 时，可用 `setup.ps1 -Python <python.exe完整路径>` 指定解释器。 |
| 其他项目没有录音技能 | 在本项目运行 `.\scripts\install_skill.ps1`，保留程序目录，再开启新的 Codex 聊天。仅复制仓库技能目录不足以安装程序。 |
| 没有实时文字 | 确认模型 ready、面板正在录音、计时与音量条有变化，检查系统所选麦克风。安静时没有文字是正常情况。 |
| 总结提示找不到 Codex CLI | 检查安装路径；新版本会在旧路径失效时寻找 PATH 或当前 Codex 桌面应用中的 CLI，不代表一定需要重新登录。 |
| 登录、网络或额度错误 | 按具体错误处理；可用 `codex login status` 检查登录，之后重新生成总结。 |
| 更新代码后界面仍旧、修复没出现 | 正在打开的页面不会自动加载新 JavaScript。**先停止并保存录音，再刷新面板**。不要在正在录音时刷新。 |
| 需要更新程序 | 先停止录音并确认保存；在没有未处理本地改动时运行 `git pull --ff-only`。让 Codex 检查依赖变化、重新运行个人技能安装脚本；后台 Python 有变化时安全重启服务，再等待暖机并刷新面板。不要覆盖本地配置和录音目录。 |

使用过程中保持 Codex 浏览器面板打开。强制关闭、崩溃、休眠或断电可能丢失尚未提交的最后几秒音频。服务重启会恢复最近一次已保存记录，不会自动打开麦克风。
